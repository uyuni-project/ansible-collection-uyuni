Plugin Index

These are the plugins in the uyuni_project.uyuni collection:

Modules

  • apply_highstate module – Apply a host’s highstate

  • apply_states module – Apply states for a host

  • clp_promote module – Promote CLP version

  • clp_version module – Create CLP version

  • full_pkg_update module – Perform full package update

  • install_patches module – Install patches

  • install_upgrades module – Install upgrades

  • is_reboot_required module – Check if system requires reboot

  • openscap_run module – Schedule OpenSCAP runs

  • reboot_host module – Reboot a managed host
