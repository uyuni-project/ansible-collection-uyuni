uyuni_project.uyuni.inventory inventory – Uyuni inventory source

Note

This inventory plugin is part of the uyuni_project.uyuni collection (version 0.4.5).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install uyuni_project.uyuni.

To use it in a playbook, specify: uyuni_project.uyuni.inventory.

  • Synopsis

  • Parameters

  • Examples

Synopsis

  • Get inventory hosts from the Uyuni API.

  • Uses a configuration file as an inventory source, it must end in .uyuni.yml or .uyuni.yaml.

Parameters

Parameter

Comments

Hostname/IP address of the Uyuni server.

If the value is not specified in the inventory configuration, the value of environment variable UYUNI_HOST will be used instead.

  • Environment variable: UYUNI_HOST

Examples

---
# my.uyuni.yml
plugin: uyuni_project.uyuni.inventory
host: 192.168.180.1
user: admin
password: admin
verify_ssl: false
show_custom_values: true
ipv6_only: true
groups:
  - dev
  - demo
...

---
# for use in AWX / AAP (Inventory Source "Sourced from a Project"),
# together with a custom credential that injects environment variables UYUNI_HOST, UYUNI_USER, UYUNI_PASSWORD
plugin: uyuni_project.uyuni.inventory
show_custom_values: true
...
