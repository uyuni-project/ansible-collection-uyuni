uyuni_project.uyuni.apply_states module – Apply states for a host

Note

This module is part of the uyuni_project.uyuni collection (version 0.5.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install uyuni_project.uyuni.

To use it in a playbook, specify: uyuni_project.uyuni.apply_states.

Synopsis

  • Apply states for a host

Parameters

Parameter

Comments

name

string / required

Name or profile ID of the managed host

states

list / elements=string / required

Name of states to apply

test_mode

boolean

Only simulate applying the states

Choices:

  • false ← (default)

  • true

uyuni_host

string / required

Uyuni API endpoint URL

uyuni_password

string / required

Uyuni login password

uyuni_port

integer

Uyuni API endpoint port

Default: 443

uyuni_user

string / required

Uyuni login user

uyuni_verify_ssl

boolean

Verify SSL certificate

Choices:

  • false

  • true ← (default)

Examples

- name: Apply states
  uyuni_project.uyuni.apply_states:
    uyuni_host: 192.168.1.1
    uyuni_user: admin
    uyuni_password: admin
    name: server.localdomain.loc
    states:
      - backup-agent
      - monitoring-agent
      - lolcat

- name: Simulate applying states
  uyuni_project.uyuni.apply_states:
    uyuni_host: 192.168.1.1
    uyuni_user: admin
    uyuni_password: admin
    name: server.localdomain.loc
    states:
      - backup-agent
      - monitoring-agent
    test_mode: true
